CHANGE RECORDS
==============

The changes are separated into two independent submission sets:

  readme_changes_local.txt
    Changes under LFGD_Recon_Simu. These are local study/tree-maker changes.

  readme_changes_container.txt
    Change to the nd280Geant4Sim package in the container installation.

Do not submit the container/package change together with the local
LFGD_Recon_Simu changes.
